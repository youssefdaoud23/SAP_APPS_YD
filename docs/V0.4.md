# Invarture App Studio v0.4

v0.4 focuses on day-to-day usability, safer testing and SAP project promotion workflows on top of the secure connector introduced in v0.3.

## New workspace settings

Open **Settings** and scroll to **Experience & runtime**.

- Light, dark or system theme
- Invarture blue, navy, teal or violet accent
- Compact, comfortable or spacious density
- Rounded, soft or square corners
- Higher-contrast mode
- Reduced-motion mode
- Configurable live SAP refresh: manual, 5, 15, 30 or 60 seconds
- Default Studio preview device
- Confirmation before runtime OData POST/PATCH/DELETE actions
- Browser-level demo read-only safeguard
- Manual live-data refresh
- Platform diagnostics

The read-only option is intentionally a browser UI safeguard. Server-side SAP authorization remains the actual security boundary.

## Productivity

### Command palette

Press **Ctrl+K** on Windows/Linux or **Cmd+K** on macOS.

The palette can jump to platform sections and directly open applications.

### Application templates

The Applications page now exposes a **Templates** action with starter applications for:

- Blank business app
- Approval workspace
- Master-detail app
- Operations dashboard

Templates are normal App Studio applications after creation and can be modified freely.

### Validation

The Studio top bar now contains **Validate**. It checks common structural problems including:

- empty applications/pages;
- duplicate component IDs;
- missing binding paths;
- missing imported server connections;
- incomplete OData write-button configuration.

### Duplicate app

The Studio top bar now supports one-click application duplication while remapping generated page/component IDs.

## Advanced app settings

Open an app in Studio and choose **App settings+**.

Available settings include:

- launchpad group;
- featured/favorite flag;
- hide from Overview;
- runtime start page;
- live or mock/design-time data mode;
- runtime page-navigation mode;
- application runtime accent.

Mock mode keeps the Studio design data visible without calling the configured SAP service.

## OData query builder

Select a data-bound Table, KPI, Chart or field and choose **Query builder**.

The visual builder supports:

- EntitySet/path
- `$select`
- `$filter`
- `$orderby`
- `$top`

The generated path is written back to the selected component binding.

## Environment remapping

Choose **Remap environment** from Studio after importing at least two server connections such as DEV and QAS.

The helper can replace one connection with another across:

- component `dataSource` references;
- OData button-action connections.

It can automatically create an application snapshot before making the change. This is intended as a lightweight promotion helper, not a replacement for SAP transport governance.

## Diagnostics

**Settings > Platform diagnostics** checks:

- browser workspace availability and approximate size;
- HTTPS state;
- PWA service-worker state;
- persistent workspace API reachability;
- SAP connector reachability and configured server connection count.

## Suggested v0.4 test flow

1. Pull `main` and hard-refresh the browser so the updated service worker activates.
2. Open Settings and try Dark mode, Compact density and a different accent.
3. Change live SAP refresh to Manual and verify **Refresh SAP data now** still updates bound components.
4. Press Ctrl/Cmd+K and open an application from the command palette.
5. Create a Master-detail application from Templates.
6. Use **App settings+** to set its start page and runtime accent.
7. Bind a Table to an imported server connection.
8. Use Query builder to add `$select`, `$filter` and `$top`.
9. Run Validate.
10. If DEV/QAS connections are imported, use Remap environment with **Create snapshot first** enabled.
11. Run Platform diagnostics.
12. Test a configured write action with confirmation enabled, then enable demo read-only mode and verify the UI blocks it.

## Security notes

- SAP passwords, bearer tokens, API keys and OAuth client secrets remain server-side.
- Runtime write actions still use the connector's SAP CSRF/session handling.
- UI read-only mode does not replace server-side SAP authorization.
- Keep `.env` out of source control.
